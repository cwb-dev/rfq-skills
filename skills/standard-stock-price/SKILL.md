# 标准件现货查价与联动计算

用于标准件现货查价。输入为询价行及已核查的平台选项。输出包括搜索结果记录、选项 JSON 和双页 Excel。不要发送邮件或下单。

## 原则

1. 先保留客户原始标准、尺寸、牙型、等级和表色，再查等效标准。常见映射：
   - DIN 912 → ISO 4762 / GB/T 70.1（平台也可能写 GB70-76、GB70-85）。
   - DIN 933 → ISO 4017 / GB/T 5783；特30/GB30 只能作为非标候选，不能叫完全等效。
   - DIN 934 → ISO 4032 / GB/T 6170 仅属同类产品，不得默认叫完全等效；M10/M12/M14/M22 对边及多种规格厚度可能不同。有 DIN 934 原标准现货时优先原标准，替代项必须标出实际尺寸差异。
2. 所有标准紧固件都以图纸要求和性能等级为优先项，不限于螺栓。先查原标准，再查等效标准；等效标准也必须核对平台图纸。检查头型、头径/对边、头高/厚度、内六角、牙距、全牙/半牙、长度和特殊说明。与公开标准库（如 https://standard.fastencloud.com/）或可靠标准资料对照。标准号相同但备注写“厂标”“实际仅达6级”时，不得当作满足原等级。DIN 912 滚花型可以纳入候选，不得仅因“滚花”排除。
3. 网站未写全牙/半牙时，不得猜；看图纸。全牙不能擅自替代半牙，半牙也不能替代全牙。图纸没有某要求时标“图纸未注明/无网站图纸”，不要补值。
4. 只有图纸和等级搜寻完毕、完全没有符合项时，才推荐替代等级，并标“需客户确认”。存在符合项时，不得为了低价或 MOQ 默认降级：
   - 原等级缺货时优先找同等级，再找更高等级。5.8/5级完全没有符合项时，可找标4.8/4级、但材料实际可能达到5级的选项，例如 Q235；Q195 只能列为低等级备选，不能声明满足5级/5.8级。
   - 6.8/6级及以上完全没有符合项时，可推荐 8.8/8级候选。
   - 材料可放宽，但性能等级必须明确标注；不能用材料名代替机械性能。
5. 镀层不匹配时推荐最接近的工艺和颜色，并写明差异。白锌、蓝白锌、彩锌、发黑不是同一要求。
6. 有图纸和等级符合的产品时，MOQ 不作硬性筛选，也不因 MOQ 改用低等级产品。在符合项中按实际采购成本选择，而非只选最低单价。记录实际购买量 `max(需求量, 向上至MOQ)`。若高 MOQ 选项单价更低，必须保留在备注中，写清单价、实际购买量、多买数量和成本差异。
7. 库存不足、无匹配、无图纸、卖完下架、厂标、实际等级降低都要明确记录。不要把搜索结果数量当作匹配商品数量；搜索可能返回其他标准。

## 工作流程

### 1. 整理询价行

每行保存：行号、客户标准、描述、数量、材料/等级、表色、牙型、默认选项、报价分类。报价分类建议：`原标准/等效`、`等级替代需确认`、`表色待确认`、`MOQ待确认`、`不匹配/无货`。

### 2. 生成查询计划

```bash
python skills/standard-stock-price/scripts/make_search_plan.py <data.json> <queries.json>
```

`data.json` 至少包含 `items`。脚本生成两平台的原始标准、等效标准和替代查询 URL。它只是计划生成器，不代替浏览器查询。

### 3. 浏览器并行查询

- 使用 Kimi Code 内置浏览器。若价格显示“会员可见”，打开登录页提醒用户登录；不要索要密码。
- 可多开标签并行查询。每个选项记录平台、条码/料号、标准、规格、材料/等级、表色、页面单价、单重、MOQ、库存、包装、匹配情况、图纸核对、备注和来源 URL。
- 工品一号可打开“图纸”弹窗读取尺寸；淘钉钉同时读取商品备注和牙型。搜索条码/料号可快速回到具体商品。
- 记录页面原价/折后价；用于计算的价格口径必须一致。不要将附条件满减自动计入。
- 将结果保存为 `<inquiry>/<no>_价格选项.json`，并另写查询及图纸复核说明。

### 4. 选项 JSON 格式

顶层字段：`inquiry`、`query_date`、`margin`、`vat_divisor`、`currency`、`price_unit`、`items`、`options`。

`items` 每行包含：
`line, standard, description, quantity, material, finish, default, group, note`。

`default` 格式为 `平台｜条码或料号`，例如 `工品一号｜KSJ785897`；无默认时为空字符串。

`options` 每行包含：
`line, platform, code, standard, spec, material_grade, finish, price, weight, moq, stock, pack, match, drawing, remarks, group`。

- 价格默认按元/千件；单重为 kg/千件；MOQ、库存为件。未知数值用 `null`。
- 每个条码/料号的备注只在该选项记录一次，脚本会保存到隐藏数据页供两页联动。
- 可在选项中加 `url`；未加时时脚本按平台生成条码查询链接。

### 5. 生成双页 Excel

```bash
python skills/standard-stock-price/scripts/build_stock_workbook.py <data.json> <out.xlsx>
```

输出：
- **报价汇总**：单价、单重、MOQ、实际采购量、采购成本、margin、未税成本、Price to Client、客户总价等；按报价分类汇总。
- **平台查询**：每行客户询价都有条码/料号下拉框；选项直接标“完全符合”或具体差异（等级、牙型、表色、图纸、库存等），并附 MOQ。选择后平台、价格、单重、MOQ、库存、包装、图纸核对和备注自动切换。此页不含客户报价列。
- **选项数据**：隐藏辅助页，保存所有选项及每行下拉列表。可取消隐藏检查，但不要删除，否则联动失效。

公式使用 Excel/WPS 兼容的 `INDEX/MATCH`、`IFERROR`、`CEILING`、`ROUNDUP`、`SUMIF`。打开文件后允许自动计算。

### 6. 校验

- 行号连续；默认选项必须存在于该行的选项中；同一行同一平台的条码/料号不可重复。
- 每个有库存的选项有价格、MOQ、库存及匹配备注；未知单重保持空白。
- 第二页每个客户行都有独立下拉列表，第一页价格、单重、MOQ、采购量和报价均引用第二页。
- 用另一选项替换默认选择，检查公式指向是否正确；不能只检查文件能否打开。
- 汇总按报价分类分开，不把“需确认”项混入原标准/等效汇总。
